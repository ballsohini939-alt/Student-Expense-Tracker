# 💰 Student Expense Tracker

A Python command-line application for managing and analyzing student expenses.

## 📌 About

Student Expense Tracker helps users record daily expenses, organize them into categories, analyze spending, search and delete expenses, and monitor a personal budget.

Expense data is stored locally using CSV file handling.

## ✨ Features

* ➕ Add expenses
* 📅 Automatic expense date
* 💰 Calculate total expenses
* 📂 Category management
* 📊 Category-wise spending analysis
* 🔎 Search expenses
* 🗑️ Delete expenses
* 💵 Set a budget
* 📈 View budget usage
* ⚠️ Budget warnings
* 💾 CSV data storage
* 🛡️ Input validation
* 🔄 Persistent data

## ▶️ How to Run

Make sure Python is installed.

Check it with:

```bash
python --version
```

Run the application:

```bash
python main.py
```
